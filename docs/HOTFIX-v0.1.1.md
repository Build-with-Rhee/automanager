# Automanager 0.1.1 기록 시작 핫픽스

마이크가 없거나 저장한 입력 장치가 사라진 PC에서 기록 시작을 누르면 `Requested device not found` 오류로 전체 기록이 중단되는 문제를 수정했다.

- 선택한 마이크 ID가 사라졌으면 시스템 기본 마이크로 한 번 다시 시도하고, 성공하면 장치 설정을 기본 마이크로 변경한다.
- 마이크가 없는 상태에서 화면과 음성을 함께 요청하면 화면과 작업 단계 기록을 시작한다. 음성이 기록되지 않는다는 안내를 표시하고 세션에도 실제 녹음 상태를 저장한다. 다음 기록의 마이크 사용 설정은 유지한다.
- 음성만 요청했는데 마이크가 없으면 연결·설정 안내를 표시한다. 마이크 권한 거부, 장치 사용 중, 화면 캡처 오류는 구분해서 안내한다.
- 설정의 마이크 확인도 같은 장치 대체 처리를 사용하고, 연결이 끊긴 장치와 새로 연결한 장치를 표시한다.

기존 기록의 저장 형식은 동일하다. 실행 중인 기존 앱을 종료한 뒤 0.1.1 Windows x64 설치 파일로 업데이트하면 된다.

검증에는 마이크가 없는 실제 Electron/X11 환경의 화면·주석 저장과 일시정지·재개, 합성 마이크의 장치 ID 대체·WAV 저장, 권한 거부 시 시작 취소가 포함된다. Windows CI는 설치 파일에 포함된 실제 프로그램에서도 장치 오류와 시작·정지 경로를 검사한다. 합성 미디어 검사는 실제 하드웨어 품질 검증과 구분한다.
